### [Auto2offer](https://github.com/Jay0130-a/Auto2offer)

面向个人求职者的 AI 招聘沟通协同智能体，覆盖：

`发现岗位` -> `匹配评估` -> `生成招呼` -> `安全校验` -> `人工审批` -> `发送消息` -> `会话应答`

重点是让自动化停留在可控、可审查、可回退的边界内。

<br clear="right" />

## 工作原则

- 先复现，再修复；把失败场景固化成回归测试。
- 对跨平台差异保留显式边界，不依赖隐式环境行为。
- 优先设计清晰的契约、错误信息和可观测性。
